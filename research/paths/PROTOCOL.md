# Frozen independent workload evaluation

Registered on 2026-11-20 before collecting SQLite authorization traces or computing rankings. Reconnaissance covered availability, pinned versions, DDL, SQL format and filenames. This study measures column-read permissions for finite reporting contracts. It tests a source of path evidence that a completed workflow cycle alone cannot supply.

**Units.** Use every SQL statement in JOB (gregrahn/join-order-benchmark at a39603662e023e449cb2121997a5034df9e02ebf) and STATS-CEB (Nathaniel-Han/End-to-End-CardEst-Benchmark at 670cb8d4bf4cbfa32f94fdf17f33973d3fd67d1b). JOB families use the upstream numeric filename stem. STATS families use the sorted set of FROM relations, extracted before scoring. This groups queries by schema shape and is a favorable setting for a table-aware comparison. For STATS strip the cardinality prefix and PostgreSQL timestamp casts on literals. Use SQLite's native authorizer on freshly prepared SELECT statements on the published empty schemas. Record any other compatibility amendment and every exclusion. Schema column read and SQLite's table-only read, where applicable, are permission units. The initial policy allows the full schema.

**Fold.** Within every family of at least three query IDs, use an ordered triple of distinct variants: one observed path O, one candidate sibling D available for preflight and one hidden future path H. Enumerate all triples up to 512 per family; above that, take the 512 lowest SHA-256 hashes of ordered IDs. D stands for a staged alternative, independent of which future variant is scored. The evaluation contract is O plus H. Reads used exclusively by D are counted as excess for that contract. Treat the split as retrospective, without implying chronology. Singletons and pairs may contribute to cross-family popularity. Report their exclusion from target folds. A path is a whole SQL variant. An observed completed query cycle can leave other variants unexercised. The registry pilot separately evaluates actual training-window boundaries in constructed warm/cold scenarios.

**Rankings.** Preserve O in all methods. Rank other schema permissions by (a) uniform tie, (b) table touched in O then read frequency among SQL queries from *other* families, (c) membership in preflight D then the same table/frequency keys, (d) a placebo replacing D with a deterministic random within-table mask with identical per-table cardinalities among unobserved columns, then the same keys. Also measure the raw policies O and O union D. The fitting function sees no H or intended-set labels. No parameter selection on either corpus.

**Primary comparison.** At 95% removal of contract-excess permissions, permit exactly floor(0.05 E) of the E excess grants. For each rank order the scorer takes the longest prefix at that allowance. Average uniformly over order within ties. Use the same favorable stopping rule for every method. With g needed and b excess items in the boundary tier and r excess slots left, expected needed items retained from it are g(r+1)/(b+1). If all remaining needed items lie there, whole-query success probability is C(g+r,g)/C(g+b,g). A needed item in a later tier makes whole-query success zero. Test both formulae by direct small enumeration. Primary outcome is preparation success for H among folds requiring at least one read absent from O. Average folds within family, then give informative families equal weight within each corpus. Report the paired sibling-minus-table/frequency estimate, counts and a descriptive family bootstrap interval (2,000 resamples, seed 20261120). Families are convenience samples, so intervals describe corpus sensitivity.

**Secondary checks.** Report all-fold results including trivial repeats, success and distinct-read retention at 100%, 90% and 75% excess removal, the within-table placebo, and an operational budget of four additional grants chosen before scoring. Break fixed-budget ties by SHA-256 of the permission name. Reprepare H with the proposed policy enforced and compare with set containment. Repeat matched scoring on columns of tables touched in O or D, retaining hidden reads outside this restricted universe as explicit misses. Provide per-query traces, fold IDs, denominators and results. Define excess only relative to the bounded workload contract.

**Interpretation.** Agreement across corpora with a meaningful gain over the table/frequency baseline and placebo supports a claim about this evidence in these workloads. Ties, reversals, narrow eligibility, dependence on operating point or costly additional grants narrow that claim. No claim about general cloud IAM or production incident prevalence follows from these benchmarks. Complete the paper with this defined evidence, systematic sensitivity checks and a direct discussion of contradictory findings.
